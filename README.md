# Student Performance Prediction System

## Project Overview
The Student Performance Prediction System is a web-based application developed using Python and Flask. It helps administrators manage student academic records and predict students' final marks using Machine Learning.

## Live Website
https://student-performance-prediction.ethiodeploy.app/

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Scikit-Learn
- Pandas
- NumPy
- Chart.js

## Main Features
- Administrator Login
- Student Record Management
- Add, View, Edit and Delete Student Records
- Student Performance Prediction
- Linear Regression Machine Learning Model
- Performance Classification
- Prediction History
- Dashboard with Data Visualisation
- Student Data Export

## Machine Learning
The application uses a Linear Regression model to estimate final marks based on:
- Study Hours
- Attendance
- Previous Marks

Predictions are classified into:
- Excellent
- Average
- Needs Improvement
